# Agent 输出与场景验收（2026-10-06）

## 本轮修正

- 账户回复改成逐账户分行显示余额、可用金额、待处理金额；不同币种不直接相加。
- 外币等值按冻结的 `ExchangeEquivalent.value` 读取，同时显示 `DEMO_RATE` 与转换时点。原评测 fixture 曾错误地把该对象写成扁平结构，已与 OpenAPI 对齐。
- 指定“美元账户”或“日元账户”时只列出该币种账户。
- “这个月转给 Lin Wei 多少钱”走只读交易历史；允许“转给”与英文姓名之间有空格，并按收款人筛选。
- Web 转账步骤显示可读的中英文操作名和状态，取消按钮提供中文译文。

| 输入                            | 应看到什么                                                             | 本轮观察                                                                  |
| ------------------------------- | ---------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| `我有多少钱？`                  | 逐账户原币余额、可用余额、待处理额及外币估值来源；不跨币种求和         | 已在浏览器看到分行回复；随后发现并修复外币对象解析                        |
