# AI Banking 比赛演示：人工测试表

日期：2026-10-01。适用范围：本地 Demo 环境；金额、产品和交易都只是模拟数据。

## 准备

1. 启动 PostgreSQL、Spring Banking Core、Python Agent Runtime 和 Next.js Web。后端使用 `demo,local` profile；Agent 的 DeepSeek key 只通过进程环境变量传入。当前本机 Web 地址为 `http://localhost:3000`，Banking Core 为 `http://localhost:18080`，Agent 为 `http://127.0.0.1:18101`。重启方法见 [交付报告](../milestones/competition-agent-demo-report.md)、[后端集成说明](../frontend/backend-integration.md) 和 [Agent Runtime README](../../services/agent-runtime/README.md)。
2. 用普通浏览器窗口登录 Alex；用无痕窗口或另一浏览器配置登录 Lin。**两个 `localhost` 端口不隔离 Cookie**，同一浏览器配置的两个普通窗口会共享 Session。
3. 测试前记下两人的 CNY Current 余额。测试金额使用 ¥10.00，避免意外重复操作。切勿把演示环境指向真实支付网络。
4. 每次测试后记录通过/失败、实际回执 ID、屏幕截图及问题。测试失败时先检查四个服务的健康状态和浏览器网络面板；不要反复点击“确认转账”。
