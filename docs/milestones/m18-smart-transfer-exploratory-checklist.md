## 每题记录

- 输入原话和是否复用原任务；自然表达、口语表达、省略表达各试一版。
- 页面任务状态、工具步骤、候选人或复核单的金额/对象/时间。
- 确认前、取消后、重复点击确认后的账户余额、意图、转账、schedule 或 AA 请求状态。
- 错误对象、无匹配对象、网络失败时是否安全停止，是否出现凭空 ID 或直接执行。
- 不将密码、验证码、完整卡号或会话 Cookie 粘贴到 Agent 对话中。

M18.3 的 H01–H10 已通过隔离环境自动验收；人工浏览器测试需要先在演示账户准备相应真实历史记录。M18.4–M18.5 已有聚焦的真实模型和数据库验收，但上表的 S01–S04、A01–A04 仍未逐项完整计分，不能据此宣称 M18 PASS。
