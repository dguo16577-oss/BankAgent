An identical account-balance prompt was run through both interfaces against one disposable bank fixture. Both tasks ended `SUCCEEDED`, selected `list_accounts`, and left PostgreSQL balances and financial-intent counts unchanged. One matched sample measured 3,223 ms for AG-UI and 4,335 ms for Legacy; repeat samples varied, so this is a smoke comparison rather than a performance conclusion. Both delivered a final answer; AG-UI also delivered tool progress events. DeepSeek is nondeterministic, so equal prompts do not guarantee equal model call counts or tool paths beyond the observed sample. Docker Desktop recovered and the full Spring Testcontainers suite passed. The first ASGI smoke attempt failed with `CSRF_TOKEN_REQUIRED` because its test client did not refresh the token after login; the smoke client was corrected without changing bank CSRF rules. The first browser attempt exposed the `demo` profile's empty CORS allowlist, so only the disposable browser test supplies `http://localhost:3000` explicitly. A refresh test exposed that reinserting recovered transcript messages into CopilotKit's live agent prevented a later run. The page now renders the recovered transcript separately and fetches the pending bank task through the owned thread-state route; the complete refresh → cancel → new DeepSeek run path passes. Repeated hostile-note queries did not cause a financial action, but answer quality was unstable.
