## 功能边界

- 本项目使用合成客户与演示资金，不提供真实银行服务。
- 金融操作必须独立确认；导航、接受协助和模型回答都不能替代授权。
- 执行结果不确定时保持待核实，不自动重新提交，不从可变卡片或代扣状态倒推出过去操作成功。
- 非转账动作仍缺完整的执行 Intent 到不可变回执定位能力。
- 新版本完整浏览器断线恢复、RAG/MCP 真实攻击送达和统一审计仍有未完成项。
- S1 安全、R1 可靠性及完整发布验收仍为 PARTIAL；不能将页面整理视为验收通过或生产就绪。
- 无法核实数据覆盖或图表对账时必须披露问题；知识来源不能授权金融操作。

## 开发检查

安装 Node.js >=22.12、pnpm 11、Python；Spring 开发还需要 JDK 21 与 Docker。

```powershell
pnpm install --frozen-lockfile
pnpm repo:check
pnpm contract:check
pnpm typecheck
pnpm test
pnpm test:agent
```

保留自动化测试、隔离数据集、安全检查、冻结 OpenAPI 和全部历史 Flyway migration。它们是维护功能的工程资产，不在产品页面展示。浏览器使用单 Worker，构建、浏览器与 Spring 大套件串行运行。

所有故障注入、真实金融副作用测试只使用可抛弃隔离库，不使用保留的演示数据库。源码仓库不包含密钥、Cookie、数据库备份、模型权重或本机日志。
