# 验证范围与运行边界

## 当前范围

系统用于合成客户、模拟资金和演示验证环境。默认单 Agent，知识服务、MCP 及多 Agent 实验模式按配置启用；服务是否在线、镜像是否包含当前源码，须以部署核验为准。

支持某项工具不等于所有真实模型与浏览器场景均已通过。各模块实现见[文档目录](README.md)，测试入口见[测试说明](testing/README.md)。

## 金融与数据边界

- 银行核心是余额、状态、授权和执行的权威。模型只能读取、分析与准备；导航及接受协助不能替代金融确认。
- 执行结果不确定时先核验，不自动重新提交。非转账业务的完整不可变回执恢复仍需按业务类型完善。
- 无法核实的数据覆盖与金额一致性应明确披露；检索文档及知识关系不能授权金融操作。
- 金融故障注入与实际模拟扣款仅使用专用可抛弃数据库，不使用保留的演示库。
