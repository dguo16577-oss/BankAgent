# Deferred issues — M11

Only issues observed in the current implementation are listed. They are not implemented in this milestone.

| ID   | Description                                                                                                                                                                                                                  | Impact                                                                                                                                        | Suggested milestone              |
| ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------- |
| D-01 | MSW resolves a single local session; credential transport, CSRF and secure session storage are not defined by a real server. The contract freezes logical per-operation session requirements with explicit extensions.       | Backend must select and document transport before real authentication/SDK integration; browser demo security is not production authorization. | M12 design / M16 security        |
| D-02 | Atomicity and idempotency are currently one-process persist-before-replace operations backed by sessionStorage.                                                                                                              | Multiple server workers need database transactions, ownership scoping, idempotency uniqueness and retention.                                  | M14–M17                          |
| D-03 | Demo account balances are opening snapshots plus later mutations; the finite transaction history does not reconstruct all opening balances. FX equivalents are fixed demo valuations and only CNY mutations are implemented. | Backend ledger reconciliation and valuation services cannot infer initial balances from the sample history alone.                             | M13 / M17                        |
| D-04 | Catalog fees are descriptive reference text; eligibility, rates and editorial content have no publication/review system.                                                                                                     | They must not drive real fees, underwriting or product availability decisions.                                                                | Later Public content integration |
| D-05 | Existing same-origin API client has no deployed backend credential/CSRF adapter; MSW is enabled by default for the demo.                                                                                                     | Disable mock loading and validate the selected session transport when integrating a real backend.                                             | M18                              |

Agent, new products and new workflows are excluded by scope, rather than recorded as defects. Automated axe checks are not a full WCAG certification or a substitute for future assistive-technology/user testing.
