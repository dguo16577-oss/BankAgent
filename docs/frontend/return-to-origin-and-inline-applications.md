# 登录返回原页面与产品页内申请

登录入口会携带触发登录的页面路径、查询条件和锚点。登录成功后返回该地址；直接打开登录页且没有来源时返回银行首页。只接受同站相对地址，拒绝外站地址、登录循环和 API 地址。

银行卡和个人贷款产品详情页的“立即申请”定位到本页申请区。未登录时先登录再回到该申请区；已登录时直接填写、检查并提交。提交结果以及刷新后重新读取的申请状态均留在产品页。个人银行的“我的申请”继续作为汇总入口。

复用现有申请组件、API、会话、CSRF 和后端持久化逻辑，没有新增合同、数据库迁移或审批功能。

本地生产预览通过 `start` 运行时，需要在构建完成后重启进程，才能加载新的路由与页面代码。
